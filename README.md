# Lohklar

Orientierung in der medizinischen Rehabilitation. founded by Kerlwerk.

Für Sozialarbeiter:innen. Klar-o-Mat, Fallordner mit Antragsweg, Wartezeit-Schätzung, Lohlotse, offizielle Klinik-Steckbriefe (13-Block-Vorlage).

Auth und Datenbank sind an. Regeln: `AGENTS.project.md`.

```bash
npm install
npm run dev
```
